## Public-data-only policy

Release 0.2 and all planned scientific extensions use published literature and publicly accessible, rights-recorded digital datasets only. The project does not require OHRI internal specimens, unpublished institutional experimental data, proprietary biological records, physical tissue, or new wet-lab acquisition. Public accessibility does not itself authorize rebundling or public deployment; asset-level attribution and rights gates still apply.

The next development cycle is defined in `docs/PUBLIC_DATA_ONLY_ROADMAP.md`. It prioritizes reproducible public-source registration benchmarks and condition-bounded molecular/spatial datasets while preserving the existing `OBS/REG/INF/SCH/SYN` distinctions.

## Geometry semantics

- `OBS`: directly measured geometry in its stated source frame.
- `REG`: registered geometry with a recorded transform and validation.
- `INF`: interpolated or derived reference representation.
- `SCH`: literature-supported schematic pathway.
- `SYN`: synthetic prototype geometry.

Adding a `REG` object requires source accession, rights, native and target coordinate spaces, a transform checksum, held-out registration error, and curator review. A display transform or visually plausible placement is not registration.
