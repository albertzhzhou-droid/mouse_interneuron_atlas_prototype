# Curator release notes — candidate 2.7

**Workbench release:** `ohri-mouse-interneuron-public-data-workbench-2.7.0`  
**Curator distribution:** `2.7.0-curator.1`  
**Scope:** named private curator review only; not authorized for public deployment or public release.

Candidate 2.7 adds `UPG-020`, an independent authorization-evidence packet composer. It turns a fixed declared, unacquired source object and a `UPG-019` plan identifier into a browser-local request for independent rights or data-steward review. The export records five planned review stages and a proposed reviewer/evidence locator; it does not authenticate the decision, authorize access, retrieve or retain source data, calculate a local hash, inspect content, create an external provenance package, or create a registration.

The package continues to contain a frozen research MVP, the `UPG-015` feasibility planner and package-coverage gap boundary, the `UPG-016` two-lane provenance trace, the `UPG-017` not-admitted relationship proposal, `UPG-006` metadata-only source-admission review, `UPG-018` assertion provenance, and `UPG-019` authorization plan. The project remains a seven-source public-data workbench, not a complete cell census, same-cell or same-specimen join, coordinate transform, causal model, or biological atlas. It contains **0 registrations**.

`UPG-021` is intentionally only a research-watch item. It requires a separately authenticated independent authorization record for the exact object and rights statement before any execution or retention SOP can even be proposed.

Use the packaged `START_HERE.html`, verify the supplied ZIP SHA-256, run the localhost launcher, and complete the independent feedback form. A curator review does not authorize public release, external acquisition, source-object retention, or `REG`.
