# Curator release notes — 1.8.0-curator.1

**Workbench release:** `ohri-mouse-interneuron-public-data-workbench-1.8.0`  
**Distribution:** private named-curator review only  
**Registrations:** zero registrations

Public deployment, public hosting, and public redistribution are not authorized for this candidate.

## What changed

Candidate 1.8 replaces the single-session Tabulae spatial panel with a browser-local source-local comparison board. A researcher can select up to four unique, declared `GSE234774` gzip triplets and inspect them side by side. The browser validates the exact filename triplets, decompresses them locally, draws each image/spot overlay in its own card, and can export only a minimal receipt of names, local SHA-256 values, parser counts, and scale factors.

This is not inter-section alignment, an image overlay, a quantitative contrast, an ordered stack, a three-dimensional reconstruction, a cell call, a treatment-effect result, a source-to-project transform, or `REG`. There is no automatic download, external request, upload, persistence, source-file bundle, or hidden project dataset.

The underlying archive remains unbundled; publisher checksum and asset-level reuse remain unresolved for project admission. The review package contains contracts and interfaces, not raw Tabulae images, coordinates, or expression data.

## Scientific boundaries

The evidence payload is frozen: all seven evidence entities remain `SYN` with `SCH` paths; reference anatomy is `INF`; the five NeuroMorpho examples are unregistered source-local `OBS`; and the project registration count remains **0**. The workbench is not a complete interneuron census, connectome, clinical tool, treatment recommendation, or human cell-type causal model.

The 1.8 catalog has seven public-source leads and thirteen upgrade gates. `UPG-012` remains the necessary source-frame/3D eligibility gate. `UPG-013` is a separate research-watch gate for any multi-section interpretation or quantitative concordance and cannot turn side-by-side cards into spatial correspondence.

The Tabulae condition index remains eight condition groups and 93 distinct literal labels under `SOURCE_METADATA_CONDITION_INDEX_ONLY`. No GEO source-file body or processed metadata is bundled. It cannot create a whole-spinal-cord atlas; the workbench retains 0 registrations.
