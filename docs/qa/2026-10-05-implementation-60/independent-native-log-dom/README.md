Original actions retain {name,startUTC,endUTC,error}. Sidecar action.windowUTC copies only the exact original start/end; ownerEvidence explains the isolated operation and explicit request allocation. Waiting/unavailable require zero scoped anchor option keys, no report pairs/link/Remove controls and no enabled Add/scientific export. Waiting has the actual source-index waiting status.
