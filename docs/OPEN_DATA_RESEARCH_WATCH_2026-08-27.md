# Open-data research watch — 2026-08-27

Policy: public digital sources only. No physical sections, specimens, request-only image collections, unpublished institutional records, or geometry made to fill an unsupported gap.

This watch records candidate inputs for future interneuron modeling. A paper-level result or public landing page is not an admitted model asset. Each object still needs a stable file inventory, integrity checksum, explicit reuse terms, source coordinate frame, specimen/sample denominators, and a source-local display before any registration proposal.

## Shared admission contract

Every candidate must retain age, sex, segment/region, specimen/sample, assay, source namespace, source-local axes/units/origin, object version, checksum and licence. Type mappings permit one-to-many, ambiguous and unknown outcomes. Connectivity remains partitioned as `direct`, `functional`, `projection_overlap`, `proximity` or `modelled`; only evidence explicitly testing a direct synaptic relation may use the direct class.

The current negative morphology result is also retained: this search found no adult-mouse spinal-interneuron single-cell morphology repository that improves on the admitted NeuroMorpho route while also providing public direct files and clear redistribution terms. Missing complete axons, non-lumbar coverage and animal-level independence therefore remain empty rather than being synthesized.
